# NEXPLAY

Painel de gestão de clientes e revendedores para serviços de streaming autorizados.

**Status:** preparação de publicação; ainda não há aplicação implantada.

## Infraestrutura
- Next.js / TypeScript na Vercel
- Neon PostgreSQL (banco já criado)
- Autenticação e gestão de assinaturas no backend

## Segurança
Não enviar arquivos `.env`, senhas, tokens ou URLs com credenciais ao repositório.

## Publicação
O código-fonte integral está no pacote NEXPLAY_Neon_v4_pronto_para_deploy.zip, preparado na conversa. A aplicação ainda precisa ser carregada neste repositório antes de habilitar deploy de produção.
